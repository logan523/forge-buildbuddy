# Agent skills (exported)

Generated by `npm run skills:export` from `src/lib/skills/catalog.ts`.

```bash
npm run skills:export
# → agent-skills/forge/<skill-id>/SKILL.md

# Claude Code example (install only what you need):
cp -r agent-skills/forge/i2c-ssd1306 agent-skills/forge/wire-one-net ~/.claude/skills/
```

```bash
npm run mcp:server
```
