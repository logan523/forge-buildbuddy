# Catalog part GLBs (optional)

Drop real `.glb` files here to override parametric catalog meshes:

| File | Part |
|------|------|
| `esp32_c3.glb` | MCU |
| `oled_096.glb` | OLED |
| `tp4056.glb` | Charger |
| `cell_16340.glb` | Battery |
| `sht30.glb` | Sensor |
| `ttp223.glb` | Touch |
| `solar_cell.glb` | Solar module |

Until files exist, the viewer uses high-detail **parametric catalog** meshes (open-source Three.js). Prefer CC0 / license-clear assets.
